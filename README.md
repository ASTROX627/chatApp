<p>Backned:</p>
<ul>
  <li>🟦 TS</li>
  <li>🌱 Node</li>
  <li>🍃 MongoDB</li>
  <li>⚡ Socket.IO</li>
  <li>🚀 Express</li>
  <li>🔑 JWT</li>
</ul>
<p>Frontend:</p>
<ul>
  <li>🟦 TS</li>
  <li>⚛️ React</li>
  <li>🎨 Tailwind CSS</li>
  <li>📦 Zustand</li>
  <li>🌐 Axios</li>
  <li>🔨 Vite</li>
</ul>
<p>Some Features:</p>
<ul>
  <li>🔑 Authentication</li>
  <li>🗨️ Messaging</li>
  <li>➕👤 Add Member / New Group</li>
  <li>🎨 Theme Switch</li>
  <li>🌐 Change Language</li>
</ul>

<h2>Build The app</h2>

```shell
cd frontend
npm run build
```

<h2>Start the app</h2>

```shell
npm run start //in the root
```
